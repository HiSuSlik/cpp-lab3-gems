# Лабораторная работа №3. Игра GEMS

## Назначение
Приложение реализует игру типа GEMS с графическим интерфейсом на базе **SFML**. Игровое поле состоит из цветных камней. Игрок выбирает один камень, затем соседний. Если после обмена образуется связная группа из трёх и более камней одного цвета, группа удаляется. После удаления выполняются падение элементов, заполнение пустых мест и повторная проверка каскадов.

## Реализованные возможности
- обмен двух соседних камней по щелчкам мыши;
- поиск связных групп размера 3 и более;
- удаление найденных групп;
- падение элементов вниз;
- каскадная обработка повторных совпадений;
- бонус **перекраска**;
- бонус **бомба**;
- графический интерфейс без консольного режима.

## Бонусы
- **Перекраска**: меняет цвет клетки-источника и двух несоседних клеток в радиусе действия на цвет исходного камня.
- **Бомба**: удаляет 5 клеток, включая клетку с бонусом.

## Структура проекта
- `include/Config.h` — параметры окна, поля и анимации;
- `include/Types.h` — базовые перечисления, координаты и вспомогательные типы;
- `include/BoardElement.h`, `src/BoardElement.cpp` — базовый класс элемента поля, стандартный элемент и классы бонусов;
- `include/Board.h`, `src/Board.cpp` — состояние игрового поля, хранение элементов и логика обработки групп, падения и бонусов;
- `include/Game.h`, `src/Game.cpp` — окно приложения, обработка ввода и визуализация;
- `src/main.cpp` — точка входа;
- `CMakeLists.txt` — файл конфигурации сборки.

## Требования
- Windows 10/11;
- компилятор C++ с поддержкой стандарта C++17;
- CMake;
- Git.

Библиотека SFML подключается автоматически через `FetchContent` в `CMakeLists.txt`, отдельная установка SFML не требуется.

## Сборка и запуск

Проект собирается в Windows с помощью CMake.

### Порядок запуска
1. Открыть командную строку или Developer PowerShell.
2. Перейти в папку проекта.
3. Запустить файл `build_windows.bat`.
4. После успешной сборки исполняемый файл создаётся в папке `build\Release`.

### Запуск
Запустить файл `GemsLabSFML.exe` из каталога `build\Release`.

## Сборка в IDE
Проект может быть открыт в любой среде разработки с поддержкой CMake. Для запуска необходимо открыть корневую папку проекта, выполнить конфигурацию CMake и собрать цель `GemsLabSFML` в конфигурации `Release`.

## Управление
- левая кнопка мыши по камню — выбор камня;
- левая кнопка мыши по соседнему камню — попытка обмена;
- успешный обмен запускает удаление групп и каскады.
